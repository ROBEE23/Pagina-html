Fundamentos Teóricos

1. Uso de la etiqueta HTML <canvas> y Contextos 2D

La etiqueta <canvas> es un contenedor rectangular en HTML5 que permite renderizar gráficos de mapas de bits dinámicamente mediante scripts. El contexto getContext('2d') provee los métodos y propiedades necesarios para dibujar formas, trazos, rellenos y aplicar transformaciones geométricas.

2. Fundamentos de la Librería p5.js

p5.js es una biblioteca de JavaScript diseñada para facilitar la programación visual e interactiva. Utiliza una estructura basada en la función setup() para configuraciones iniciales y el bucle continuo draw() que se ejecuta múltiples veces por segundo para animar gráficos de forma eficiente.
